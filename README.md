# GP_VQA: Knowledge Graph-enhanced Medical Visual Question Answering for Chest X-rays

**GP_VQA** (Graph-based Visual Question Answering) is an advanced end-to-end framework designed to answer clinical questions based on chest X-ray images. By integrating **Computer Vision**, **Medical Knowledge Graphs**, and **Large Language Models (LLMs)**, GP_VQA moves away from traditional "black-box" models, providing clinically accurate, complete, and highly explainable answers (Explainable AI).

---

## 📖 Project Overview

Clinical Visual Question Answering (VQA) on chest radiographs is a critical yet challenging task in computer-aided diagnosis. Standard multimodal VQA models often suffer from a lack of clinical reasoning, vulnerability to hallucination, and a complete absence of interpretability, which limits their utility in real-world clinical decision support.

To address these limitations, **GP_VQA** introduces a modular pipeline that decouples *visual perception* from *cognitive reasoning*:
- **Perception:** A multi-task vision encoder detects global pathology labels (14 CheXpert categories) and localizes abnormal medical entities.
- **Ontology Ingestion:** Standardized medical terms and semantic relations from **UMLS** and **SNOMED CT** form a permanent static knowledge graph (static backbone) inside Neo4j.
- **Dynamic Anchoring:** Vision predictions are anchored dynamically to the static graph, creating a patient-specific evidence network with explicit confidence weights.
- **Knowledge Retrieval & Generation (GraphRAG):** When a user asks a question, the system parses the intent and retrieves the relevant subgraphs (evidence paths). An LLM then processes these structured facts to generate a natural, clinically grounded answer alongside its exact reasoning trace.

This architecture ensures that every medical diagnosis generated by the LLM is fully auditable and directly linked to visual evidence and established medical literature.

---

## 🌟 Key Features

1. **Multi-task Vision Analysis:**
   - **Global Classification:** Utilizes a **Rad-DINO** backbone for multi-label classification across 14 CheXpert pathology categories.
   - **Local Localization:** Integrates a **MedSAM/MedSAM3-based** encoder with smart LoRA weight-matching to pinpoint local anatomical abnormalities.
2. **Clinical Language Understanding & NER:**
   - Identifies question intent (e.g., *existence*, *location*, *abnormality*) and extracts clinical entities using a multi-task **ALBERT-BiLSTM** model alongside a robust rule-based extractor.
3. **Hybrid Medical Knowledge Graph (Neo4j):**
   - **Static Graph (Medical Backbone):** Populated with standardized clinical terms and hierarchical relationships from medical ontologies including **UMLS** and **SNOMED CT**.
   - **Dynamic Graph (Patient Evidence):** Anchors dynamic vision-extracted features from specific patient images as weighted evidence nodes (`EXHIBITS` relations with confidence scores).
4. **GraphRAG & Hierarchical Reasoning (U-Retrieval):**
   - Traverses the knowledge graph to retrieve logical evidence paths such as `Finding -> SUGGESTS -> Disease` and `Finding -> LOCATED_AT -> Anatomy`.
   - Formulates structured, context-rich prompts for the LLM to generate precise clinical explanations in Vietnamese/English.

## 🚀 Installation & Quick Start

### 1. Requirements
* Python 3.10+
* **Neo4j Database** (either a local Docker container or a cloud-hosted Neo4j AuraDB instance)

### 2. Setup Virtual Environment
Initialize and activate your Python virtual environment, then install dependencies:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 3. Environment Variables
Create a `.env` file in the root directory based on `.env.example` and add your database and LLM credentials:
```env
NEO4J_URI=bolt://localhost:7687
NEO4J_USERNAME=neo4j
NEO4J_PASSWORD=your_password
OPENAI_API_KEY=your_openai_api_key
```

### 4. Initialize Knowledge Graph (Static Ingest)
Apply database constraints, indices, and load the static medical ontology backbone:
```bash
# Setup Neo4j schema and unique constraints
python scripts/kg_plan_smoke_test.py

# Ingest static medical dictionary priors
python scripts/kg_ingest_static.py
```

### 5. Run the Local VQA Chatbot Demo
Execute the orchestrator directly from the command line:
```bash
python scripts/run_vqa_demo.py \
  --image_path path/to/sample_cxr.jpg \
  --question "Does the patient have pleural effusion?" \
  --run-vision
```
